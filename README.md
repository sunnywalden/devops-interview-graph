# DevOps 面试研习室

温暖浅色的离线学习工作台，按「语言基础 → 中间件与容器 → 场景实战」练习知识与表达。使用 React、TypeScript、Vite 和 Ant Design；无后端、统计服务或运行时 CDN，构建产物包含依赖并使用系统字体。

## 开发与验证

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
npm run preview
```

`npm test` 使用 Node 内置测试运行器和项目已有 Vite 加载器，覆盖书签迁移、路由校验、偏好记忆、浏览记录去重、损坏数据、存储失败与恢复、跨标签通知、课程数据完整性及图示失败清理。测试使用独立的临时缓存，不会使正在运行的开发服务依赖失效。

浏览器图示回归：开发服务运行时打开 `/tests/mermaid-browser.html`。默认两张错误图示应仅在各自区域显示提示，页脚后没有错误 SVG；点击「正常图示」应显示两张时序图，点击「卸载图示」后不应留下图示。这一页面使用真实 Mermaid 与 React StrictMode，不包含在生产构建中。

构建结果在 `dist/`，资源采用相对路径。复制整个目录后通过静态服务器打开即可；直接使用 `file://` 可能受到浏览器 ES module 限制。首次安装依赖需要网络。Mermaid 的部分按需加载图形引擎仍会触发构建的大分块提示。

## 界面与练习

- 总览：继续上次学习、三条学习路线、真实浏览进度、五个 STAR 项目、3/5 天冲刺计划和知识图谱。
- 课程页：分组切换、带目标名称的大按钮翻页与可筛选目录；页尾提示本组后续内容并可继续下一组；浏览记录仅表示打开，不代表学完或掌握；口述优先，追问、原理、易错点和图示逐层展开。
- 专注口述：收起导航和辅助内容；退出按钮或 Esc 返回，输入法组合输入期间不抢占 Esc。
- 键盘：聚焦卡片区域或翻页导航后，左右方向键或 j/k 切卡，Home/End 到首尾；目录支持筛选、方向键、Enter 和 Esc。表单、分组选择和目录保留自身键盘行为。
- 图示：Mermaid 与 React Flow 按需加载；图谱可平移并使用控件缩放，滚轮保留页面滚动。图示加载失败时仅在卡片内提示，可刷新重试；临时渲染容器始终清理，正文继续可读。
- 布局适配桌面、平板和手机，提供跳到正文、可见焦点和减少动态效果支持。

## 书签与阅读记录

| 入口或动作 | 行为 |
| --- | --- |
| 首次打开 | 显示学习总览 |
| 无 hash 再次打开 | 恢复最近保存的位置 |
| 完整深链 | URL 优先；无效分组或知识点先校验，再回退并保存有效位置 |
| `#/lang`、`#/mid`、`#/scene` | 恢复该层上次位置 |
| `#/overview` | 打开总览的学习路线 |
| `#/overview/star`、`#/overview/plan` | 恢复项目或计划各自的选择 |
| 切换课程分组 | 打开该组默认知识点 |
| 总览「继续上次学习」 | 打开最近有效的课程知识点，排除总览自身 |

书签存储于 `devops-kg-bookmark`，v2 格式保留 `current` 和独立的 `byPage` 槽位，兼容旧版扁平书签。`devops-kg-ui-prefs` 保存专注模式、图示偏好、项目与冲刺选择、各层已浏览卡片。进度只统计仍存在的不同知识点，表示浏览足迹，不表示掌握程度。

同一浏览器的其他标签页更新记录后，概况会同步。存储被禁用或空间不足时，页面继续保留当前会话的数据，并显示「本次会话暂存」；刷新可能丢失这些尚未落盘的数据。成功再次写入相应存储项后恢复持久保存。

清除全部记录：在浏览器开发者工具的 Local Storage 中删除上述两个键，再刷新。示例深链：`#/lang/go/chan`、`#/overview/star/mingfu`、`#/overview/plan/3d`。

## 内容与代码

| 内容 | 文件 | 数量 |
| --- | --- | --- |
| 语言基础 | `src/data/language.ts` | 25 张 |
| 中间件与容器 | `src/data/middleware.ts` | 45 张 |
| 场景实战 | `src/data/scenarios.ts` | 30 张 |

课程合计 100 张卡片。图示定义位于 `src/data/visuals-*.ts`，经 `attachVisuals` 挂载。内容由原有 Canvas 迁移，保留原有项目口径；简历指标不补造。

路由规范化位于 `src/routing.ts`；学习概况由 `src/study.ts` 根据真实课程与书签计算；`src/storage.ts` 和 `src/useSavedState.ts` 负责持久存储降级及订阅。回归测试在 `tests/study-state.test.mjs`。
